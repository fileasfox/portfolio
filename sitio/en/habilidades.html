How this portfolio is built

No templates or frameworks: a Python generator and my own JavaScript.

  1. AnalysisPython writes the results to JSONpandas
  2. Generatorbuild.py assembles each page in Spanish and English with header, footer and dataPython
  3. ChartsSVG drawn with JavaScript from the JSONJS and SVG
  4. SQL consoleSQLite compiled to JavaScript, running in your browsersql.js
  5. DesignEditorial system, red palette, light and dark themesCSS

Automatic audit before publishing

auditoria.py checks the generated site in both languages: secrets, personal data, the employer's internal names, external links and scripts, CSP, JavaScript sinks, image metadata and that every section is within 3 clicks. If a check fails, nothing is published.

Tables, charts, the console and the simulator read the analysis results directly: if the data changes, rerunning the analysis and the generator is enough.
